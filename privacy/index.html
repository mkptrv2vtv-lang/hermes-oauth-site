Privacy Policy

Hermes Alexey is a private personal assistant used only by authorized users.

Google user data

The application may access Google services such as Gmail and Google Calendar only after the user explicitly authorizes access through Google OAuth.

Purpose of access

Google data is used solely to provide personal assistant functionality requested by the authorized user.

Data storage

OAuth credentials and application data are stored in the user's private Hermes environment and are not made publicly available.

Data sharing

Google user data is not sold and is not shared with advertisers.

Revoking access

Users can revoke the application's access at any time from their Google Account security settings.
